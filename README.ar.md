# ctxguard

هوك صغير لـ Claude Code يمنع الجلسات الطويلة من استنزاف حدود الاستخدام بصمت. كل رد يعيد قراءة السياق كله، فجلسة بحجم 300 ألف توكن تكلّف أكثر بكثير لكل رسالة من جلسة جديدة. ctxguard يقيس حجم السياق الحالي وعمر الجلسة من سجل المحادثة وينبّه Claude (وإياك) إلى إنهاء الخطوة والتسليم لجلسة جديدة.

- بايثون بالمكتبة القياسية فقط، بلا نموذج ولا شبكة ولا اعتماديات.
- ما يعطّل جلستك أبداً: أي خطأ يطبع لا شيء وينتهي بالرمز 0.
- يعمل على ويندوز ولينكس وماك (بايثون 3.8 فما فوق).

## التثبيت

أضف البلجن من الماركت بليس أو حمّله محلياً:

```
claude --plugin-dir /path/to/ctxguard
```

يسجّل البلجن هوكين (`UserPromptSubmit` و`PostToolUse`) يشغّلان `scripts/ctxguard.py`. يحتاج `python` أو `python3` في PATH. لا يعتمد أي أدوات مسبقاً ولا يطلب صلاحيات.

## السلوك

| المستوى | الشرط (الافتراضي) | ما يحدث |
|---|---|---|
| خفيف | سياق >= 150 ألف توكن أو عمر >= 6 ساعات | يُضاف تذكير: أنهِ الخطوة، اختصر، احفظ الملاحظات، واقترح جلسة جديدة. |
| قوي | سياق >= 250 ألف توكن أو عمر >= 9 ساعات | تعليمة أقوى: لا وكلاء ولا Workflow جديد، أنهِ الخطوة وسلّم. |
| حجب (اختياري) | سياق >= 500 ألف توكن و`block_enabled` مفعّل | تُحجب الرسالة برسالة توضيحية إلا إذا وُجد ملف التجاوز. |

في `UserPromptSubmit` يُضاف التذكير لكل رسالة. في `PostToolUse` يتكرر فقط بعد نمو السياق 25 ألف توكن أو مرور 30 دقيقة. الحجب يحصل فقط في `UserPromptSubmit` وهو مطفأ افتراضياً.

## الإعداد لكل مشروع

أنشئ `.claude/ctxguard.json` في مشروعك (كل المفاتيح اختيارية):

```json
{
  "soft": 150000,
  "strong": 250000,
  "block": 500000,
  "age_soft_h": 6,
  "age_strong_h": 9,
  "block_enabled": false
}
```

القيم أرقام موجبة (النص والقيم المنطقية مرفوضة)، و`block_enabled` لازم قيمة منطقية حقيقية، والترتيب soft <= strong <= block و age_soft_h <= age_strong_h. أي قيمة غير صالحة تُسقط الملف كله وتُطبَّق الافتراضيات، فخطأ إملائي ما يفعّل الحجب أبداً.

للاستمرار في جلسة محجوبة رغم ذلك: أنشئ ملفاً فارغاً `.claude/ctxguard.override` في المشروع وامسحه بعدها.

## متغيرات البيئة (للاختبار)

`CONTEXT_GUARD_SOFT` و`CONTEXT_GUARD_STRONG` و`CONTEXT_GUARD_BLOCK` (توكن)، `CONTEXT_GUARD_AGE_SOFT` و`CONTEXT_GUARD_AGE_STRONG` (ساعات). تغلب ملف المشروع؛ القيم غير الصالحة تُتجاهل.

## الخصوصية والحدود

- يقرأ فقط مسار السجل الذي يعطيه Claude Code للهوك (آخر ~400 كيلوبايت وأول سطر) وملفات الإعداد أعلاه.
- يكتب فقط ملف عدّاد صغير في مجلد temp (`ctxguard_<session>.txt`).
- حجم السياق يُؤخذ من آخر سجل `usage` (إدخال + قراءة كاش + إنشاء كاش)؛ تقدير وليس بيانات فوترة.
